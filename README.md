# Окошко (Okoshko Web) — Telegram Mini App 💅✨

Telegram Mini App для сервиса онлайн-записи в салоны красоты и к частным мастерам («Окошко»). Интерфейс разработан в эстетике **Apple Liquid Glass / iOS Frosted Glass** (матовое стекло, мягкие тени, нативные анимации).

---

## 📱 Функциональность

- 🗺️ **Интерактивная карта и категории**: поиск салонов и топ-мастеров, фильтры по категориям (Маникюр, Стрижки, Брови, Массаж, Педикюр), плавающий Bottom Sheet с быстрыми слотами.
- 💇 **Страница салона (Beauty Studio)**: статус работы («Открыто до 21:00»), фотогалерея, карусель мастеров, каталог популярных услуг с прайс-листом и отзывы клиентов.
- 💅 **Профиль топ-мастера (Алина Романова)**: бейджи Telegram, интерактивный календарь свободных окошек по дням, выбор слотов времени, чекбоксы услуг с динамическим подсчетом суммы и длительности.
- 📅 **Мои записи**: активные визиты, маршрут до салона, перенос, отмена и связь с мастером через Telegram.
- 👤 **Профиль клиента**: бонусы, статистика записей, настройки уведомлений и переключатель в режим мастера PRO.
- 🪟 **iOS Frosted Glass**: эффект матового стекла (`backdrop-filter: blur(28px) saturate(200%)`) на навигационном меню, верхней панели и плавающих карточках.

## 🚀 Запуск на локальном сервере

Для запуска достаточно любого статического веб-сервера (например, Python):

```bash
python -m http.server 3000
```

После запуска откройте в браузере:
👉 **[http://localhost:3000](http://localhost:3000)**

## 📁 Структура проекта

- `index.html` — главное SPA-приложение Telegram Mini App (Яндекс.Карты, Telegram-верификация, экраны записи)
- `bot.py` — точка входа/раннер бота (перенаправляет вызов в пакет `bot`)
- `bot/` — модульный Telegram-бот на **aiogram 3**:
  - `config.py` — загрузка `.env` и валидация настроек
  - `keyboards/` — инлайн и реплай клавиатуры с WebApp кнопками
  - `handlers/` — роутеры команд (`/start`, `/help`, `/app`) и приёма данных бронирования
  - `main.py` — главный диспетчер и опрос (polling)
- `requirements.txt` — зависимости Python (`aiogram`, `python-dotenv`)
- `.env` — файл конфигурации с токеном бота и ссылкой на Mini App
- `.env.example` — шаблон переменных окружения
- `stitch_design/` — исходные изолированные экраны и спецификации дизайна

## 🤖 Запуск Telegram-бота (aiogram 3)

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка `.env`
Откройте файл `.env` в корне проекта и укажите ваш токен бота от [@BotFather](https://t.me/BotFather):
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
MINI_APP_URL=https://noisy18.github.io/okoshko_web/
```

### 3. Запуск бота
```bash
python bot.py
```

### 4. Возможности бота
- 🔘 **Native Menu Button**: при входе в чат у пользователя сразу появляется кнопка «💅 Окошко» в строке ввода Telegram.
- 📱 **Inline-кнопка**: открытие Mini App прямо из приветственного сообщения `/start`.
- ⌨️ **Нижняя клавиатура**: быстрый доступ к приложению и разделам «О сервисе» и «Помощь».
- 📩 **Обработка бронирования**: при подтверждении записи Mini App передаёт данные в чат бота, и клиент получает карточку подтверждения визита.
